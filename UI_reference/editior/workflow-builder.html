Start
Entry point for the workflow.

A run begins when the user sends a message in chat with this workflow. There's nothing to configure here.

Agent
System prompt and tools. The agent decides which enabled tools to call, looping until it produces a final answer.

Can you calculate an 18% tip on $84.50, and tell me today's date for my receipt?
Start node_start
Workflow triggered by new chat message.
Agent agent
tool_call calculator({ "expression": "84.50 * 0.18" })
node_result { "result": 15.21 }
tool_call get_current_datetime({})
node_result { "datetime": "2026-07-28" }
Condition branch
node_result needs_escalation == false → Else
End final
Workflow completed.
An 18% tip on $84.50 is $15.21. Today's date is 2026-07-28 — you can use that on your receipt.
